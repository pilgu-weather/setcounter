# Set Counter 다국어·지역별 법률 검토

기준일: 2026-08-12

이 문서는 출시 실무 체크리스트이며 법률 자문을 대신하지 않는다.

## 결론

- 앱에 여러 언어를 포함하는 행위 자체는 개인정보 수집이나 국외 이전을 새로 발생시키지 않는다.
- 실제 법적 의무는 앱을 특정 국가에 배포하거나, 그 지역 이용자를 대상으로 서비스를 제공하고 개인정보를 처리할 때 달라질 수 있다.
- 1차 Google Play 배포 국가는 대한민국만 선택한다. 언어 선택에는 한국어, 영어, 일본어, 스페인어, 중국어 간체, 러시아어를 유지할 수 있다.
- 번역 제공은 해당 언어권 국가에 출시할 준비가 끝났다는 의미가 아님을 이용약관과 개인정보 처리방침에 명시했다.
- 새 번역 런타임이나 외부 번역 SDK를 앱에 포함하지 않았다. 번역 문자열은 저장소의 정적 JavaScript 자산으로만 제공하므로 별도의 사용자 데이터 전송은 없다.

## 공통 스토어 기준

### Google Play

- 게시글·댓글 작성 전에 이용약관 또는 사용자 정책을 수락해야 한다.
- 공개 UGC에는 콘텐츠·사용자 신고와 사용자 차단 기능, 지속적인 운영 조치가 필요하다.
- 계정 생성 앱은 앱 내부와 앱 밖의 공개 웹 경로에서 계정 및 연계 데이터 삭제를 제공해야 한다.
- 개인정보 처리방침과 Data safety 답변은 실제 데이터 처리와 일치해야 한다.

현재 반영:

- 게시글·댓글 작성 전 `2026-08-12` 버전 커뮤니티 약관 동의
- 금지 콘텐츠에 아동 착취·학대 자료를 명시
- 신고, 차단, 차단 해제, 콘텐츠 제한·삭제, 계정 정지·해지 절차 유지
- 앱 내부 계정 삭제와 `/account-deletion` 공개 삭제 경로 유지

### Apple App Store 참고

- UGC 앱에는 부적절한 콘텐츠 필터링, 신고, 사용자 차단, 공개 연락처가 필요하다.
- 계정 생성 기능이 있으면 앱 안에서 계정 삭제를 제공해야 한다.
- 제3자 처리자가 개인정보 처리방침과 동등한 보호를 제공하는지 개발자가 확인해야 한다.

## 언어별 검수 결과

| 언어 | UI 제공 | 법률 문구 | 출시 상태 |
|---|---:|---|---|
| 한국어 | 예 | 기준 원문 | 대한민국 1차 출시 |
| 영어 | 예 | 원문 의미와 데이터 처리 범위 대조 | 국가 추가 전 현지 검토 |
| 일본어 | 예 | 기계 번역의 계정·의료·국외 처리 오역 수정 | 일본 추가 전 현지 검토 |
| 스페인어 | 예 | 개인정보 권리·국외 이전·준거법 용어 정리 | 국가별 소비자법 검토 후 추가 |
| 중국어 간체 | 예 | 잘못된 번호·기관명·계정 삭제 번역 전면 수정 | 중국 본토 배포 보류 |
| 러시아어 | 예 | 계정·의료 안내·푸시·준거법 용어 전면 수정 | 러시아 배포 보류 |

## 국가·지역별 출시 게이트

### 대한민국

- 현재 공개 정책과 Data safety 표를 실제 Render·Neon·Discord·Web Push 설정과 다시 대조한다.
- 사업자 정보, 실제 서버 리전 또는 외부 처리자가 달라지면 정책을 먼저 갱신한다.

### EU/EEA 및 영국

- 현지 제공 전에 처리의 법적 근거, 관리자의 완전한 신원·주소, 정보주체 권리 처리 절차, 감독기관 진정 안내, 국외 이전 근거를 법률 전문가와 확인한다.
- 현재 문서는 권리와 감독기관 진정 가능성을 안내하지만 EU/EEA 출시 완료를 의미하지 않는다.

### 일본 및 스페인어권 국가

- 일본 APPI와 각 스페인어권 국가의 개인정보·소비자보호·전자상거래 요구사항을 국가별로 검토한다.
- 스페인어 하나로 여러 국가의 법률 요건이 같아지는 것은 아니므로 Play Console 대상 국가를 일괄 활성화하지 않는다.

### 중국 본토

- PIPL은 중국 내 개인에게 서비스를 제공하거나 그 행동을 분석하는 국외 처리에도 적용될 수 있다.
- 중국 본토 출시 전에 현지 대표자, 개인정보 국외 이전 절차, 별도 동의, 수신자 고지, 앱·인터넷 서비스 등록 또는 ICP 관련 요건을 현지 전문가와 확인한다.
- App Store 또는 Play 이외 채널을 포함해 중국 본토 배포를 현재 상태에서 활성화하지 않는다.

### 러시아

- 러시아 거주자 개인정보를 수집할 때 적용될 수 있는 현지 데이터베이스 저장·통지·국외 이전 요건을 현지 전문가와 확인한다.
- 러시아 대상 광고, 스토어 배포 및 현지 운영을 현재 상태에서 활성화하지 않는다.

## 배포 전 필수 확인

- [ ] Play Console 대상 국가는 대한민국만 선택
- [ ] 앱 내 `/terms`, `/privacy`, `/account-deletion`을 6개 언어에서 열어 문장 잘림과 원문 잔존 확인
- [ ] 게시글과 댓글 작성 전 약관 동의가 실제 기기에서 작동하는지 확인
- [ ] Play Console Data safety 답변과 운영 데이터 흐름 재대조
- [ ] 새 국가 추가 요청마다 이 문서를 다시 검토하고 정책 시행일 갱신 여부 판단
