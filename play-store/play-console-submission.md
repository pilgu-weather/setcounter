# Google Play Console 제출 답변서

작성 기준일: 2026-07-31

## 앱 액세스

- 주요 기능은 익명 사용자도 가입 없이 사용할 수 있다.
- 이메일 계정 연결은 기록을 다른 기기에서 이어 보기 위한 선택 기능이다.
- 심사용 테스트 계정은 필수가 아니다.
- 로그인 전용 기능이 새로 생기면 심사 계정을 제공하고 이 답변을 수정한다.

## 광고

- 광고 포함 여부: `아니요`
- 광고 SDK: 없음

## 대상 연령 및 콘텐츠

- 권장 대상: 만 18세 이상 일반 성인 운동 사용자
- 아동 대상 앱이 아님
- 도박, 현금성 보상, 폭력 콘텐츠 없음
- 사용자 생성 콘텐츠(게시글 및 댓글) 있음
- 게시글과 댓글에 신고 기능이 있음
- 게시글 작성자와 댓글 작성자를 별도로 차단할 수 있음
- 차단 사용자의 게시글과 댓글은 서버에서 피드 응답에서 제외됨

## 건강 앱 선언

- 카테고리: `Activity and Fitness`
- 의료 기능: 없음
- 자세한 답변: `play-store/health-app-declaration.md`

## 데이터 보안

- 실제 입력 답변은 `play-store/data-safety.md`를 기준으로 한다.
- 비밀번호는 단방향 해시로만 저장한다.
- 세션 쿠키는 HttpOnly, SameSite=Lax이며 운영 HTTPS에서는 Secure를 사용한다.
- 계정 및 데이터 삭제 URL: `https://setcounter.onrender.com/account-deletion`
- 개인정보 처리방침 URL: `https://setcounter.onrender.com/privacy`
- 위 URL은 Render 연결과 공개 경로 확인 후 제출한다.

## 권한

- `INTERNET`: 웹 앱 접속과 서버 동기화
- `POST_NOTIFICATIONS`: 사용자가 허용한 경우 알림 표시
- 위치, 연락처, 카메라, 마이크, 사진, 건강 센서 권한은 요청하지 않음

## 배포 및 테스트

- 패키지명: `com.setcounter.app`
- 현재 버전: versionCode `1`, versionName `1.0.0`
- targetSdk/compileSdk: `36`
- 배포 국가: 대한민국
- 가격: 무료
- 신규 개인 개발자 계정의 비공개 테스트 요건이 적용되면 최소 12명이 14일 연속 참여해야 한다.

## 제출자가 직접 채울 값

- 실제 공개 고객지원 이메일
- 개발자 이름, 주소, 전화번호와 이메일 인증
- 개인정보 처리방침 및 계정 삭제 URL의 공개 응답 확인
- 앱 서명 인증서가 반영된 Digital Asset Links 확인
- 콘텐츠 등급 설문 최종 제출
- 데이터 보안 및 건강 앱 선언 최종 제출
- 내부 또는 비공개 테스트 기기의 설치·업데이트 검증
