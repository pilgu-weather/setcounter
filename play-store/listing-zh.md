# Google Play 商店文案（zh-CN）

## 应用名称

Set Counter

## 简短说明

快速记录组数、重量和次数，持续追踪力量训练进度。

## 完整说明

Set Counter 是一款专为力量训练设计的个人训练记录应用。

在不打断训练节奏的情况下记录重量、次数和组数，并快速查看已完成内容。你可以参考上一次训练安排下一组，也可以通过日历管理训练日与休息日。

主要功能

- 按动作记录重量、次数和目标组数
- 根据历史记录快速输入下一组
- 查看每日训练记录与训练量
- 使用训练日历和 SOS 休息记录
- 追踪等级、XP 与累计统计
- 使用包含多个动作的推荐训练计划
- 在社区分享训练记录
- 举报帖子和评论，或屏蔽其他用户
- 以访客身份开始，之后再关联电子邮箱账户
- 关联账户后可在其他设备继续查看记录

Set Counter 无需注册即可开始使用。你可以先以访客身份进入，在需要长期保存记录时再关联账户。
