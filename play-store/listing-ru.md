# Текст для Google Play (ru-RU)

## Название приложения

Set Counter

## Краткое описание

Быстро записывайте подходы, вес и повторения и следите за прогрессом.

## Полное описание

Set Counter — персональное приложение для ведения дневника силовых тренировок.

Записывайте вес, повторения и подходы, не отвлекаясь от тренировки. Сверяйтесь с предыдущими результатами перед следующим подходом и управляйте тренировочными днями и отдыхом в календаре.

Основные возможности

- Учёт веса, повторений и целевых подходов для каждого упражнения
- Быстрый ввод на основе предыдущей тренировки
- История тренировок по дням и общий объём
- Календарь тренировок и отметки дней отдыха SOS
- Уровни, XP и накопленная статистика
- Готовые планы из нескольких упражнений
- Сообщество для публикации тренировочных записей
- Жалобы на публикации и комментарии, блокировка пользователей
- Работа в гостевом режиме с последующей привязкой электронной почты
- Доступ к записям на других устройствах после привязки аккаунта

Для начала работы регистрация не требуется. Войдите как гость и привяжите аккаунт позже, когда захотите сохранить свои записи.
