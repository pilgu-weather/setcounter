# Google Play 스토어 등록 문구 (ko-KR)

## 앱 이름

Set Counter

## 짧은 설명

세트, 무게, 반복 횟수를 빠르게 기록하고 운동 흐름을 이어가세요.

## 자세한 설명

Set Counter는 근력 운동을 빠르고 꾸준하게 기록하기 위한 운동 기록 앱입니다.

운동 중 흐름을 끊지 않고 무게와 반복 횟수를 입력하고, 완료한 세트를 한눈에 확인할 수 있습니다. 이전 운동 기록을 참고해 다음 세트를 이어가고, 달력에서 운동한 날과 회복일을 함께 관리하세요.

주요 기능

- 운동별 무게, 반복 횟수, 목표 세트 기록
- 이전 기록을 활용한 빠른 세트 입력
- 일별 운동 기록과 볼륨 확인
- 운동 달력과 SOS 회복일 기록
- 레벨과 누적 운동 통계
- 여러 운동으로 구성된 추천 플랜
- 운동 기록을 공유하는 커뮤니티
- 게시글·댓글 신고 및 사용자 차단
- 익명 사용 후 이메일 계정 연결
- 계정 연결 시 다른 기기에서 기록 이어보기

Set Counter는 처음부터 회원가입을 강요하지 않습니다. 익명으로 바로 시작하고, 기록을 보관하고 싶을 때 계정을 연결할 수 있습니다.

운동 기록은 사용자가 직접 입력한 정보를 기준으로 제공됩니다. Set Counter는 의료기기가 아니며, 앱의 운동 안내는 의료 진단·치료·예방이나 전문적인 운동 처방을 대신하지 않습니다. 통증이나 부상 우려가 있으면 운동을 중단하고 의료 또는 운동 전문가와 상담하세요.

## 분류

- 앱 또는 게임: 앱
- 카테고리: 건강/운동
- 태그 후보: 운동 기록, 근력 운동, 웨이트 트레이닝
