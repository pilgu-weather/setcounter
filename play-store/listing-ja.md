# Google Play ストア掲載文（ja-JP）

## アプリ名

Set Counter

## 短い説明

セット、重量、回数をすばやく記録し、トレーニングを続けましょう。

## 詳しい説明

Set Counterは、筋力トレーニングをすばやく継続的に記録するためのワークアウトログアプリです。

トレーニングの流れを止めずに重量と回数を入力し、完了したセットをひと目で確認できます。前回の記録を参考に次のセットへ進み、カレンダーでトレーニング日と休養日を一緒に管理できます。

主な機能

- 種目ごとの重量、回数、目標セット数を記録
- 前回の記録を利用したスムーズなセット入力
- 日別のトレーニング記録とボリュームを確認
- トレーニングカレンダーとSOS休養日の記録
- レベルと累計トレーニング統計
- 複数の種目で構成されたおすすめプラン
- トレーニング記録を共有できるコミュニティ
- 投稿・コメントの通報とユーザーのブロック
- ゲスト利用後にメールアカウントを連携
- アカウント連携後は別の端末でも記録を継続

Set Counterは、最初から会員登録を求めません。ゲストとしてすぐに始め、記録を保管したいときにアカウントを連携できます。

トレーニング記録は、ユーザーが入力した情報に基づいて提供されます。Set Counterは医療機器ではなく、アプリ内の運動案内は医療上の診断、治療、予防、または専門的な運動処方に代わるものではありません。痛みやけがの不安がある場合は運動を中止し、医療または運動の専門家に相談してください。
