# Google Play 데이터 보안 제출 기준

기준일: 2026-08-08

Play Console 질문 문구가 바뀔 수 있으므로 아래 표를 실제 제출 화면과 마지막으로 대조한다. Set Counter는 TWA이므로 웹 앱에서 서버로 전송되는 데이터도 수집 범위에 포함한다.

## 기본 답변

- 사용자 데이터를 수집하거나 공유하는가: `예`
- 전송 중 암호화하는가: `예` (최종 배포 HTTPS 확인 필요)
- 사용자가 데이터 삭제를 요청할 수 있는가: `예`
- 독립적인 보안 검토를 받았는가: `아니요`
- 아동 대상 앱인가: `아니요`, 만 18세 이상 대상
- 광고 또는 광고 SDK를 사용하는가: `아니요`

## 수집 데이터

| Play 데이터 유형 | 필수/선택 | 목적 | 보관 |
| --- | --- | --- | --- |
| 개인 정보 > 이메일 주소 | 선택 | 계정 생성, 로그인, 기기 간 기록 연결 | 계정 삭제 시까지 |
| 개인 정보 > 사용자 ID | 필수 | 익명·로그인 사용자 식별과 데이터 격리 | 익명 삭제 요청 또는 계정 삭제 시까지 |
| 개인 정보 > 기타 정보(닉네임, 성별) | 닉네임 필수, 성별 선택 | 커뮤니티 표시, 묶음 운동 시작 중량 설정 | 삭제 시까지 |
| 건강 및 피트니스 > 피트니스 정보 | 선택 | 운동·세트·무게·횟수·휴식·SOS·주간 목표·통계·레벨 제공 | 삭제 시까지 |
| 앱 활동 > 사용자 제작 콘텐츠 | 선택 | 게시글, 댓글, 좋아요, 신고, 차단 | 삭제 또는 운영 조치 시까지 |
| 앱 활동 > 기타 사용자 활동 | 선택 | 피드백, 설정, 기능 진행 상태 | 목적 달성 또는 삭제 시까지 |
| 기기 또는 기타 ID | 선택 | Web Push 구독 주소와 암호화 키를 통한 알림 전달 | 구독 해제 또는 삭제 시까지 |
| 보안 관련 식별값 | 필수 | 로그인 시도 제한과 부정 이용 방지 | 마지막 갱신 후 최대 7일 |

비밀번호 원문은 저장하지 않고 서버에서 단방향 해시만 보관한다. 비밀번호를 로컬 저장소나 분석 도구로 보내지 않는다.

## 제3자 처리와 공유 판단

- Render와 Neon은 서비스 운영을 대신하는 호스팅·데이터베이스 처리자다. 최종 계약과 Play의 최신 서비스 제공자 예외 기준을 확인한다.
- Web Push 제공자는 사용자가 알림을 켰을 때만 구독 정보를 처리한다.
- Discord에는 사용자가 피드백 또는 신고를 전송할 때 닉네임, 레벨, 사용자 ID, 대상 정보와 작성 내용이 전달된다.
- Discord 전송은 일반적인 전용 처리계약이 확인되지 않았으므로 Play Console에서는 관련 `사용자 ID`, `기타 개인 정보`, `사용자 제작 콘텐츠`를 `공유함`으로 보수적으로 선언한다.
- 위치, 연락처, 사진·동영상, 오디오, 파일, 캘린더, 금융정보, 구매내역, 웹 탐색 기록은 수집하지 않는다.

## 보안과 삭제

- 운영 전송은 HTTPS만 사용한다.
- 세션 쿠키는 HttpOnly, SameSite=Lax이며 운영에서 Secure를 사용한다.
- CSRF 검증과 계정·익명 사용자 데이터 격리를 적용한다.
- 로그인 사용자는 앱 메뉴에서 계정과 연결 데이터를 삭제할 수 있다.
- 앱을 설치하지 않아도 공개 `/account-deletion`에서 이메일과 비밀번호를 확인한 뒤 삭제할 수 있다.
- 삭제 대상: 계정, 인증 연결, 프로필, 운동·세트, SOS, 레벨 이력, 게시글, 댓글, 좋아요, 신고, 차단 관계, 푸시 구독.
- 익명 사용자는 피드백 기능으로 사용자 ID에 연결된 기록 삭제를 요청할 수 있다.

## 제출 직전 확인

- 공개 개인정보 처리방침과 이 문서의 데이터 유형이 일치하는지 확인
- 실제 운영 호스트, DB 리전, Discord와 Push 처리 방식 확인
- Play Console에 공개 개인정보 처리방침 및 계정 삭제 URL 입력
- 앱의 모든 활성 서드파티 SDK와 서버 로그를 다시 조사
