# Google Play 데이터 보안 작성 기준

Play Console 질문 문구가 바뀔 수 있으므로 실제 제출 화면과 대조한다. 아래 답변은 현재 Set Counter 코드와 개인정보 처리방침을 기준으로 한 보수적인 초안이다.

## 수집되는 데이터

| 데이터 유형 | 수집 여부 | 필수 여부 | 목적 |
| --- | --- | --- | --- |
| 이메일 주소 | 계정 연결 시 수집 | 선택 | 계정 관리, 기기 간 기록 연결 |
| 사용자 식별자 | 수집 | 필수 | 익명 사용자 및 계정 사용자 식별 |
| 성별 | 묶음 운동 이용 시 수집 | 선택 | 성별에 따른 보수적인 시작 중량 프리셋 제공 |
| 운동 및 피트니스 정보 | 사용 시 수집 | 선택 | 운동·세트·무게·횟수·휴식시간, 주간 목표, 통계, 레벨·경험치, 달력 제공 |
| 앱 내 검색 기록 | 저장하지 않음 | - | - |
| 사용자가 생성한 콘텐츠 | 게시판 이용 시 수집 | 선택 | 게시글, 댓글, 좋아요, 신고 및 사용자 차단 제공 |
| 기타 사용자 생성 콘텐츠 | SOS/피드백 이용 시 수집 | 선택 | SOS 사유 기록, 고객지원 |
| 웹 푸시 구독 정보 | 알림 동의 시 수집 | 선택 | 운동 알림 발송 |
| 비밀번호 | 서버로 전송 후 해시만 저장 | 계정 연결 시 필수 | 인증 |

## 공유 및 처리

- 비밀번호 원문은 저장하지 않는다.
- HTTPS 배포 후 전송 중 암호화를 사용한다.
- 피드백과 게시판 신고 내용은 Discord 웹훅을 통해 운영자 채널로 전달될 수 있다. Play Console의 서비스 제공자/공유 예외 기준을 확인해 보수적으로 공개한다.
- 광고 SDK, 분석 SDK, 위치 SDK는 포함하지 않는다.
- 앱은 연락처, 사진, 카메라, 마이크, 정확한 위치 권한을 요청하지 않는다.
- 로그인 남용 방지를 위해 식별값을 해시 처리한 뒤 시도 횟수와 제한 상태를 저장한다. 원본 비밀번호는 저장하지 않는다.

## 삭제 및 보안

- 앱 안 메뉴에서 계정 삭제를 제공한다.
- 앱을 설치하지 않아도 `/account-deletion`에서 이메일과 비밀번호를 확인한 뒤 계정 및 연결 데이터를 삭제할 수 있다.
- 삭제 대상: 계정, 프로필, 운동/세트, SOS, 게시글, 댓글, 좋아요, 신고, 차단 관계, 푸시 구독.
- 인증 쿠키는 HttpOnly, SameSite=Lax이며 HTTPS 운영 환경에서는 Secure를 사용한다.
- 익명 사용자의 데이터는 계정이 아니므로 브라우저의 로컬 식별 키 삭제만으로 서버 데이터가 자동 삭제되지는 않는다. 이 내용을 개인정보 처리방침과 앱 안내에 일치시킨다.
- 익명 기록 삭제 요청은 앱의 피드백 보내기로 받고, 함께 전달되는 사용자 ID를 기준으로 처리한다.

## 제출 직전 확인

- Play Console의 최신 데이터 유형 명칭과 이 표를 다시 대조한다.
- Discord 전송을 데이터 공유로 표시할지 최신 정책의 서비스 제공자 예외를 확인한다.
- Render에서 HTTPS, 쿠키 Secure, 실제 개인정보처리방침 URL이 동작하는지 확인한다.
